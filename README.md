Entry for the make.fun bounty "Promote make.fun's make-your-own-bounty post on X": one post of my own on X that quotes make.fun's make-your-own-bounty post, with a promo image of my own attached and the play code in its text. The post: https://x.com/0xShinju_0/status/2124949683739218355. Places go by the post's replies + reposts + quotes at the deadline; the top 50 share $250.

## Run
`mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts` copies POST.json to out/POST.json, byte for byte. Node 22, standard library only, no network.
